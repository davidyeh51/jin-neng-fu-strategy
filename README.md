## 🎯 v10 核心升級亮點

### 1. 實際機會清單逐案對帳（53 筆案源具體化）
- **名目 Pipeline 與加權期望**：
  - 清單內名目 58.88 億、加權期望 **14.29 億**（差額 −5.71 億）。
  - 加計待補案（鉅鋼 0.21 億、台糖中安 17.50 億）後，名目達 76.59 億、加權期望達 **17.83 億**（差額 −2.17 億）。
- **揭露勝率調整的關鍵真相**：
  - 加權期望由對帳前 10.80 億升至 17.83 億（增加 7.03 億），**其中 5.22 億（74%）來自勝率參數放寬（5% 調為 20%），而非案源實質推進**！
  - 三個算力中心調高勝率即貢獻 4.50 億（佔全部改善 64%），案子本身毫無進展。
  - **管理動作**：報表上嚴格區分「20%（下限）」與「20%（評估）」，杜絕數字遊戲。
- **四大結構性問題浮現**：
  - ① **資產管理靠台糖**：台糖三案佔該軌名目 96%、加權 91%，佔全公司加權期望 **49%**。台糖一轉向，全公司腰斬至 9.1 億。
  - ② **統包量夠質不夠**：名目 10.19 億達標，但**實測平均勝率僅 24.5%**（假設 40%，落差 15.5pp）。若維持 25% 勝率，需補 5.8 億新案源。
  - ③ **三個算力中心同日決標（2026/12/31）**：疑為預設值而非客戶承諾。
  - ④ **微網實質退出**：加權僅 0.09 億（佔全體 0.5%）。
