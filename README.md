# 進能服 (6692) 事業部三年年度計畫 (FY27~FY29) v9 決策簡報

本專案基於最新的戰略底稿 `1.2.3 年度計畫_三年(FY27~FY29) v9.md` 重新改版建置。此版本大幅革新了業務分類邏輯，確立「資金來源三軌制」，並將重點聚焦於「財務數字」、「75 億 Pipeline 負荷」以及「執行落地檢核」，為事業部對內與高階管理者呈閱的最精煉實戰版。

---

## 🎯 v9 版核心更新重點

1. **確立「資金來源」三軌分類**：
   - 放棄過去依技術/場域分類的盲點。微電網因同樣為業主出錢，已併入「①統包工程」軌。
   - 新三軌：**①統包工程**（業主出錢）、**②資產管理**（公司/建坤出錢）、**③AIDC開發**（業者出錢）。
2. **Pipeline 與勝率精算重構 (總目標 75 億)**：
   - 簽約目標分配為：統包 4 億、資管 6 億、AIDC 10 億。
   - 勝率定案為：統包 40%、資管 40% (轉化率)、AIDC 20% (里程碑管理)。
   - 所需 Pipeline 大幅修正至 75 億。3 位常規業務人均負荷 8.3 億，具備高度落地可行性。
3. **三年損益表與 80% 買方集中風險**：
   - 揭露 FY27~FY29 基準情境（淨利率上看 10.5%）與保守情境的對比。
   - 點出高毛利背後的脆弱點，以及資管與 AIDC 佔比提升帶來的 **80% 客戶集中度風險**，國泰決策速度成為關鍵路徑。
4. **FY27 BP QA 查核清單**：
   - 針對業務與專管單位，設計 10 個核心實戰拷問（涵蓋資金來源辨識、內部產能排程、AIDC現金流、轉化率複盤等），作為日常營運防偏誤檢核表。
