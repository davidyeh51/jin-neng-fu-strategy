# 進能服 (6692) 成長戰略規劃 v5 (對內/董事會版) 網頁

本專案根據最新對內溝通暨董事會轉型計畫 `1.2.3 年度計畫_三年(FY26~FY28) v5.md` 重新設計並建置，採用高度視覺化（圖片、流程圖、指標卡片、對比表格與 Chart.js 圖表）取代純文字說明。

## 網頁架構 (v5 版)

- **摘要與三大主張**：告別諸侯割據（1. 序列化不並行、2. 建強中央分三年、3. 分而治之資源紀律）
- **第一部：轉型必要性**：外部產業典範位移（光伏觸頂）vs. 內部諸侯制極限與「轉型不是收權」承諾
- **第二部：方法論疊加層**：分而治之 (100%可控/策略性半可控/情境準備不可控)、3+3 框架 (功能分類版)、SPV 財務槓桿 (BOL邏輯)、管理節奏
- **第三部：雙重約束與序列化優先序**：資本 vs. 管理注意力約束、現金流時點，推導 P0 (建坤/維運) → P1 (售電/ATMOCE) → P2 (AIDC) → P3 (CPO 主動延後)
- **第四部：強中央三階段建置**：階段一 M&A 併購 (FY26) → 階段二 數據平台 (FY27) → 階段三 技術中台 (FY28) 與權責界線表
- **第五部：各事業部戰略**：建坤 (持電廠解鎖售電業)、維運 (50MW 據點門檻)、ATMOCE BTM、售電業、AIDC (富邦分工)、CPO (延後理由)
- **第六部：OKR 行動矩陣**：依 v5 優先序重排之行動目標與時限標籤 (支援 Tab 篩選)
- **第七/八部：路線與風險評估**：三年演進對照表、結構化第二意見紅隊分析、15 項待補充清單 (搜尋+優先級過濾)、一頁式決策摘要
