3. **新增 FY27 BP QA 查核清單**：
   - 針對業務（Sales）與專案管理（PM）單位，設計了 10 個核心實戰拷問（涵蓋案源門檻、內部轉撥計價、現金流防守、停損底線等）。
   - 提供各單位主管（Lucy 與 Silvia）作為 FY27 營運過程中的防偏誤檢核表。
