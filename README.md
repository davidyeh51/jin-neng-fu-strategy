  - 3.4 泓德能源競爭訊號（電力主權、容量訂閱制）與富邦能源衝突紅旗預警
- **Part 4：FY2027 業務四軌與 BP 拆解 (3 頁)**：
  - 4.1 短期光儲 (3億)、微網 (3億)、資產管理 (4億) ＋ 中期 AIDC (10億)
  - 4.2 BP 簽約 20 億 vs 落地 10 億三個結構性讀法（10 億差額來自 AIDC 跨期）
  - 4.3 業務線與事業部對照及微網組織歸屬決策樹
- **Part 5：優先序與三年路線圖 (4 頁)**：
  - 5.1 六事業部雙軸評估與現金流時間表（FY26 唯一現金牛為維運）
  - 5.2 建議優先序 P0（建坤/維運/AIDC前置）&rarr; P1（售電/ATMOCE）&rarr; P2（AIDC資本）&rarr; P3（CPO延後）
  - 5.3 FY2026–FY2028 三年戰略全要素路線圖（資本、注意力、外購、中央建置、營收、現金流全矩陣）
  - 5.4 強中央三階段建置（M&A &rarr; 知識資產化 &rarr; 技術中台）與中央地方權責界線
- **Part 6：五角色 25 問——決策抉擇 (5 頁)**：
